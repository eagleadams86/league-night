Welcome to League Night

Runs a darts league from your phone: the players or teams, a season of fixtures, the table, a leg-by-leg scorer, and knock-out tournaments. Anyone signed in to Google with the league's ID can follow it; anyone with its admin key can run it.

Nothing is uploaded unless you sign in and share a league. Until then a league lives in this browser only.

Create a League asks for a name and whether it is played as singles or in teams, and opens on the Players tab — add the people, start a season, and the fixtures generate themselves.

Join a League asks for the League ID someone sent you — and the Admin Key, if they want you running it — and signs you in to Google, because a shared league is tied to real accounts.

Try the Demo loads two invented leagues — a singles league with a season under way, handicaps, a finished knockout and a double-elimination cup in progress, and a doubles league with team matches — so every tab has something on it.

Restore a Backup reads a League Night export — the JSON file the Back Up window writes.

Back Up & Restore

One JSON file holding everything in this league — a copy you keep, independent of this browser and of the cloud.

Every match as a spreadsheet. It is a one-way door: the CSV is for reading elsewhere, and Restore reads the JSON above, never this.

Restoring a backup of a league already on this device replaces that league; a backup of another league is added beside the ones you have. You are told what the file holds and asked to confirm first.

Start Again

Deletes every league on this device. A league you have shared stays in the cloud for its members and comes back when you sign in; a league that lives only here is gone for good. Your settings and your theme are kept. To delete one league, or to delete a shared league for everyone, use the League tab.

Share a Read-Only Link

Anyone opening this link sees the league as it is right now, with no way to change it and no sign-in. Everything travels inside the link itself — nothing is uploaded, and it carries no League ID, so it is a picture of the league and not a way in.

How Much

One season keeps the link short. Tournaments ride with the season they belong to.

What to Include

Results, scores and the table ride either way; the detail is what makes a link long.

Your Link

This is a snapshot, frozen as it looks right now — later results won't appear, so send a fresh link when the table moves. There is no way to withdraw one once sent, and whoever holds it can read everything inside it.
