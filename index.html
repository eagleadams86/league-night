Welcome to League Night

A shell you can build an app on. It already carries this family's palette, type and chrome, its dialogs and charts, read-only sharing, offline and backups — and the guards that stop saved data being quietly mangled. Everything in it is a worked example of a rule the other apps follow.

Everything you enter stays in this browser. Nothing is uploaded — there is no account and no server.

Start Fresh opens an empty app on the ＋ Add Entry button — the way in if you already know what you want to record.

Load Sample Data fills every tile, the chart and the table with an invented set, so every figure on both tabs has something behind it. Each row is named for the case it demonstrates rather than being filler.

Restore a Backup reads a League Night export — the JSON file the Back Up window writes.

Back Up & Restore

One JSON file holding every entry and setting — a copy you keep, independent of this browser. With no account required to use the app, clearing your browser data is the one thing that will lose your figures.

Every entry as a spreadsheet, for anyone who keeps figures in one. It is a one-way door: the CSV is for reading and charting elsewhere, and Restore reads the JSON above, never this.

Restoring replaces everything in this browser. You are told what the file holds and asked to confirm first.

Share a Read-Only Link

Anyone opening this link sees the entries you pick, with no way to change them and no sign-in. The figures travel inside the link itself — nothing is uploaded anywhere, and it doesn't touch whatever they have saved in their own browser.

How Many Entries

Nothing is deleted — this only decides how much rides in the link, which is what keeps a long one sendable. A trimmed link shows trimmed figures: the total, the average and the chart are all worked out from the entries inside it, so they can differ from the ones on your screen. Whoever opens it is told which window they are looking at.

What to Include

Values and dates ride either way: they are the figures the link exists to show. It is the NAMES that say what a figure is about, which is why they are the thing you can leave behind.

Your Link

This is a snapshot, frozen as it looks right now — later edits won't appear, so send a fresh link when the figures move. There is no way to withdraw one once sent, and whoever holds it can read everything inside it, so treat it like emailing a spreadsheet.

Find

Every entry — by its name or its date. A result opens straight into its record, on the tab it lives on.
